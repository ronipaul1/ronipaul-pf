## About

This repository is my personal developer portfolio — not a template, not a starter kit, just the codebase behind my own site.

It's built around an interactive **Developer ID Card**, a small idea I kept coming back to: instead of just listing sections about myself, the site presents them as a digital identity — name, role, status, all on one card you can tilt and tap.

Beyond the card, the portfolio covers who I am, my frontend journey so far, my current internship, the skills I'm building, the projects I've actually shipped, how I use AI-assisted development day to day, and a few ways to reach me.

## The Idea

The interactive ID Card is the signature piece of the site — a way of treating a developer portfolio less like a stack of sections and more like a digital identity you can interact with.

The rest of the site follows that same language: interactive UI, purposeful motion, a developer-focused visual system, and a layout that stays responsive and readable wherever it's viewed. It's also where I get to apply what I've been learning about AI-assisted development, using it as part of how the site itself came together.

---

## Features

- 🪪 Interactive Developer ID Card with tilt and tap interactions
- 🎨 Custom geometric developer avatar — no stock or real photograph
- 🌗 Dark and light themes, each designed on its own terms
- ✨ Smooth animations and scroll transitions
- 📱 Fully responsive across desktop, tablet, and mobile
- 💼 Project showcase linking to live, working demos
- 🧭 Experience and education timeline
- 📬 Functional contact form
- ✉️ Brevo-powered email notifications on submission
- ♿ Accessibility-conscious interactions
- 🎛️ Reduced-motion support
